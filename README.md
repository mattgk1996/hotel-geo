# Hotel Geo: Voucher & Expense App

A web app for Hotel Geo (Bangalore) staff to photograph vouchers. The app reads each photo, files it under the right expense head, routes it for review, and shows spending on a live dashboard.

- **Stack:** Next.js on Vercel, Supabase (database, photo storage, login)
- **Spec:** see [docs/stage-a-spec.md](docs/stage-a-spec.md)
- **Stages:** A) photo capture, auto-categorisation and dashboard; B) WhatsApp approvals; C) Tally and hotel-software sync

> This repo is public. Never commit API keys or `.env` files.
